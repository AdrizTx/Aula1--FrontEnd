Marinho

Content (conteudo)

Define a largura da caixa (salvo elementos de bloco )

Padding (preenchimento)

Separar o coteudo das bordas da caixa. É a margem interna

Border (borda)

Define bordas para a caixa

Margin (Margem)

define a distancia entre uma caixa e outra

Width (largura)

A largura total da caixa, por padrão é o sematório do conteudo + padding(left/right) + border (left/right)

Height (Altura)

A altura total da caixa, por padrao é o somatório do conteudo + padding (top/bottom) + border (top/bottom)
